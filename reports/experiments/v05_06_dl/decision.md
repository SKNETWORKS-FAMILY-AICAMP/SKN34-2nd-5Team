# v05_06 개발 후보 판정

## 결론

`v05_06_dl` 모델과 개발 가중치는 생성·검증됐지만, 현재 개발 기준인 `v05_05_dl`을 교체하지 않는다.
Final Test는 사용하지 않았으며 이 판정은 동일 sample의 expanding-time OOF 결과만 사용한다.

## 기준 모델 대비

| 지표 | v05_05 | v05_06 | 변화 |
|---|---:|---:|---:|
| Macro F1 | 0.5763 | 0.5751 | -0.0012 |
| Macro PR-AUC | 0.5980 | 0.5925 | -0.0056 |
| Balanced accuracy | 0.5714 | 0.5740 | +0.0026 |
| Weakened Recall | 66.76% | 63.20% | -3.56%p |
| Stopped Recall | 43.25% | 45.16% | +1.91%p |
| 조건부 Stopped PR-AUC | 0.4672 | 0.4604 | -0.0068 |
| 중증 오분류 | 538건 | 650건 | +112건 |
| Precision@1000 | 90.60% | 90.04% | -0.56%p |
| 2017 내부 홀드아웃 Macro F1 | 0.5858 | 0.5870 | +0.0012 |

## 해석

- TCN은 stopped 예측량을 늘려 Stopped Recall을 높였지만, Weakened Recall과 stopped 순위 품질을 함께 떨어뜨렸다.
- Macro F1 차이의 사용자 단위 95% 신뢰구간은 `-0.0049 ~ +0.0028`로 0을 포함한다.
- Weakened Recall 변화의 95% 신뢰구간은 `-4.10%p ~ -2.97%p`로, 약화 리뷰어 누락 증가는 일관된 손실이다.
- Risk 점수 상관은 0.9842, 조건부 stopped 점수 상관은 0.9649로 GRU와 TCN의 순위가 매우 유사하다.
- 예측 클래스 불일치는 9.09%지만 중증 오분류가 늘어, 현 상태로는 앙상블 다양성만을 근거로 채택하지 않는다.

## 검증 상태

- 개발 데이터: selection year 2010~2017, 31,420건
- OOF ensemble: selection year 2013~2017, 24,596건
- OOF 학습: 5개 시간 폴드 × 3 seeds
- 개발 가중치: 3개 저장 및 재로딩 점수 일치 확인
- Final Test 로드·예측·평가: 0 / 0 / 0
