# DEC-004. 리뷰 활동 이탈(Churn) 정의

| 항목 | 내용 |
|---|---|
| 상태 | 승인(Approved) |
| 결정 대상 | 파워 리뷰어 이탈 예측의 타깃 라벨 |
| 적용 버전 | `v01` |
| 분석 범위 | Yelp 음식점 리뷰 활동 |
| 기준 시점 | 2018년 12월 31일 |
| 타깃 기간 | 2019년 1월 1일 ~ 2019년 12월 31일 |

## 1. 결정 요약

본 프로젝트에서 **리뷰 활동 이탈자**는 최종 분석 코호트에 포함된 사용자 중 **2019년 한 해 동안 음식점 리뷰를 한 건도 작성하지 않은 사용자**로 정의한다.

```text
churn = 1: 2019년 음식점 리뷰 수가 0건
churn = 0: 2019년 음식점 리뷰 수가 1건 이상
```

구현식은 다음과 같다.

```python
final_cohort_df["churn"] = (
    final_cohort_df["target_review_count"] == 0
).astype("int8")
```

`churn`은 미래 이탈 가능성이 아니라 **2019년에 실제로 관측된 결과 라벨**이다. 모델 학습 후 산출되는 이탈 확률과 구분한다.

## 2. 배경과 문제

프로젝트의 목적은 활발하게 음식점을 탐방하고 리뷰를 생산하던 핵심 리뷰어의 활동 루틴 변화가 이후 리뷰 활동 중단으로 이어지는지를 검증하는 것이다.

Yelp 데이터만으로는 사용자의 실제 생활 전체, 앱 접속 여부, 계정 삭제 여부를 확인할 수 없다. 따라서 본 프로젝트는 플랫폼 전체 이탈이 아니라 **Yelp 데이터에서 관측되는 음식점 리뷰 활동의 이탈**을 예측 대상으로 삼는다.

명칭 역시 의학적·심리적 상태를 확정하는 의미의 번아웃이 아니라, 리뷰량·작성 간격·탐색 범위 등 활동 루틴이 약해지는 현상을 설명하기 위한 프로젝트 용어로 사용한다.

## 3. 분석 코호트

타깃 정의는 다음 조건을 만족하는 최종 코호트에만 적용한다.

1. 2017년 음식점 리뷰를 10건 이상 작성했다.
2. 2017년 중 음식점 리뷰를 작성한 활동 월이 3개월 이상이다.
3. 2018년 하반기에 음식점 리뷰를 1건 이상 작성했다.

세 번째 조건은 예측 기준 시점과 너무 멀리 떨어진 사용자를 제외하기 위한 연속성 조건이다. 이미 장기간 활동이 없던 사용자를 2019년 이탈자로 다시 분류하는 문제를 방지한다.

현재 `v01` 코호트 결과는 다음과 같다.

| 구분 | 사용자 수 | 비율 |
|---|---:|---:|
| 최종 코호트 | 3,908명 | 100.00% |
| 유지 사용자 (`churn=0`) | 3,302명 | 84.49% |
| 이탈 사용자 (`churn=1`) | 606명 | 15.51% |

인원수는 코호트 조건을 적용한 결과이며 코드에 고정하는 기준값이 아니다. 설정값이 변경되면 결과 인원도 달라질 수 있다.

## 4. 이 정의를 선택한 이유

### 4.1 파워 리뷰어 선정 주기와 일치

파워 리뷰어를 연간 활동 기준으로 선정하므로 이탈 여부도 다음 1년의 활동을 기준으로 판단하는 것이 일관적이다. 연간 단위는 플랫폼의 리뷰어 등급·보상·리텐션 캠페인 운영에도 적용하기 쉽다.

### 4.2 해석이 명확함

리뷰 수가 일정 비율 감소했다는 기준은 사용자별 기존 활동량에 따라 의미가 달라질 수 있다. 반면 연간 음식점 리뷰 0건은 명확하고 재현 가능한 활동 중단 기준이다.

### 4.3 예측 시점의 활동 사용자만 포함

2018년 하반기 활동 조건을 함께 적용하여, 모델이 사실상 이미 이탈한 사용자를 쉽게 구분하는 문제를 완화했다.

### 4.4 코로나19 충격 회피

타깃 기간을 2019년으로 설정하여 2020년 이후 코로나19로 인한 음식점 방문·리뷰 활동의 구조적 충격을 피했다.

### 4.5 모델링 가능한 양성 표본 확보

현재 정의에서 이탈자는 606명, 이탈률은 15.51%로 나타났다. 클래스 불균형에 대한 평가지표 설계는 필요하지만 초기 분류 모델과 시간 기반 검증을 수행할 수 있는 규모다.

## 5. 검토한 대안

| 대안 | 장점 | 채택하지 않은 이유 |
|---|---|---|
| 2019년 리뷰 1건 이하 | 약한 활동 중단까지 포착 | 연 1건 작성자를 완전 이탈로 보기 어렵고 기준 해석이 모호함 |
| 리뷰 수 일정 비율 감소 | 기존 활동량을 반영 | 감소 자체가 입력 피처와 타깃에 동시에 반영될 위험이 있고 완전 중단과 의미가 다름 |
| 마지막 리뷰 후 6개월 무활동 | 조기 이탈 탐지 가능 | 계절성과 관찰 종료 시점에 민감하고 연간 운영 기준과 불일치 |
| Yelp 전체 리뷰 0건 | 플랫폼 콘텐츠 이탈에 가까움 | 프로젝트의 음식점 탐방 루틴 범위와 달라지며 비음식점 활동이 혼입됨 |
| 계정 삭제 또는 앱 미접속 | 실제 플랫폼 이탈에 가까움 | 공개 Yelp 데이터에서 관측할 수 없음 |

## 6. 데이터 및 모델링 규칙

### 6.1 입력·타깃 기간 분리

```text
선정 기간: 2017-01-01 ~ 2017-12-31
변화 관찰: 2018-01-01 ~ 2018-12-31
최근 활동 확인: 2018-07-01 ~ 2018-12-31
타깃 확인: 2019-01-01 ~ 2019-12-31
```

모든 예측 피처는 2018년 12월 31일까지 관측 가능한 정보만 사용한다.

### 6.2 미래 정보 누수 방지

다음 컬럼은 정답 생성 및 검증에만 사용하고 모델 입력에서는 제외한다.

```text
churn
target_review_count
target_active_months
2019년 이후의 리뷰·사용자 집계 정보
```

`useful`, `cool`, `funny`와 같이 반응 발생 시점을 확인할 수 없는 누적 값은 예측 기준 시점 이후 정보가 섞일 가능성이 있으므로 입력 피처에서 제외하거나 별도 민감도 분석으로만 사용한다.

### 6.3 확률과 정답 라벨의 UI 구분

분석 프로토타입에서는 다음처럼 구분하여 표시한다.

```text
실제 관측 결과: 이탈 또는 유지
예측 이탈 위험도: 모델이 산출한 0~100% 확률
```

모델을 학습하기 전에는 이탈 가능성 백분율을 표시하지 않는다.

## 7. 해석 범위와 한계

1. `churn=1`은 음식점 리뷰 활동 중단을 의미하며 Yelp 앱 미사용이나 계정 탈퇴를 의미하지 않는다.
2. 사용자가 실제로 음식점 방문을 중단했는지, 리뷰만 작성하지 않았는지는 구분할 수 없다.
3. 지역 이동, 건강, 플랫폼 전환 등 활동 중단의 실제 원인을 데이터만으로 확정할 수 없다.
4. 2019년에 리뷰가 없더라도 이후 다시 활동할 수 있으므로 영구 이탈을 의미하지 않는다.
5. 현재 결과는 하나의 연간 코호트에 기반하므로 후속 단계에서 복수 연도 롤링 코호트 검증이 필요하다.

따라서 결과 표현은 “미식 번아웃을 진단했다”가 아니라 **“음식점 리뷰 활동 이탈 위험을 예측했다”**로 제한한다.

## 8. 검증 조건

```python
assert final_cohort_df["user_id"].is_unique
assert final_cohort_df["churn"].isin([0, 1]).all()

expected_churn = (
    final_cohort_df["target_review_count"] == 0
).astype("int8")

assert final_cohort_df["churn"].equals(expected_churn)
```

추가로 다음 항목을 결과표에 기록한다.

- 최종 코호트 사용자 수
- 이탈·유지 사용자 수와 비율
- 타깃 기간 최소·최대 날짜
- 타깃 리뷰 수 분포
- 코호트 조건별 민감도 분석 결과

## 9. 재검토 조건

다음 상황에서는 본 결정을 재검토한다.

1. 앱 접속·계정 상태 등 실제 플랫폼 활동 데이터가 추가된다.
2. 2019년 외 복수 연도의 롤링 코호트를 구축한다.
3. 이탈 후 복귀를 반영하는 생존분석 또는 다중 상태 모델을 도입한다.
4. 비즈니스 운영 주기가 연간이 아닌 월간·분기 단위로 확정된다.
5. 음식점 리뷰 이외의 콘텐츠 활동을 프로젝트 범위에 포함한다.
