## 1. 배경

기존 화면은 권역 운영과 개인 운영을 별도 제품처럼 나누어 설명했다. 기능은 연결되어
있지만 운영자가 왜 권역을 보고, 왜 특정 리뷰어를 특별 관리하며, 그 결과 어떤 행동을
해야 하는지가 첫 화면에서 하나의 흐름으로 읽히지 않았다.

프로젝트의 실제 비즈니스 문제는 파워 리뷰어 분류 자체가 아니라 **지역별 리뷰 콘텐츠
공급의 변화**다. 파워 리뷰어 예측과 개인 개입은 리뷰 공급 감소의 원인을 분석하고
핵심 콘텐츠 생산자를 관리하기 위한 수단이다.

## 2. 결정

### 2.1 최종 제품 정의

> 지역별 리뷰 공급 변화를 감지하고 원인을 분석한 뒤, 파워 리뷰어 특별 관리 또는
> 지역 활성화 캠페인으로 연결하는 리뷰 생태계 운영 서비스다.

### 2.2 단일 운영 흐름

```text
리뷰 공급 변화 감지
→ 감소·둔화 권역 선택
→ 원인 분석
   ├─ 활동 리뷰어 변화
   ├─ 기존 파워 리뷰어 활동 저하
   └─ 신규 파워 리뷰어 유입 부족
→ 대응 방식 결정
   ├─ 개인: 파워 리뷰어 특별 관리
   └─ 지역: 이벤트·콘텐츠 캠페인
→ 운영 대상·실행안 저장
→ 30·60·90일 변화 관찰
```

Reviewer 360과 권역 캠페인은 독립 기능이 아니라 `리뷰 공급 회복`이라는 같은 목표의
서로 다른 대응 경로다.

### 2.3 개인 대응 경로

```text
우선 검토 큐
→ Reviewer 360 활동 근거 확인
→ 관리자 판단
→ 실행안·채널·콘텐츠 선택
→ 개인 개입안 저장
→ 30·60·90일 관찰
```

우선 검토 큐에서는 대상을 선택하고 근거를 요약한다. 근거를 충분히 확인하지 않은
상태에서 관리자 판단을 즉시 확정하지 않는다. 관리자 판단은 Reviewer 360에서 수행한다.

### 2.4 지역 대응 경로

```text
콘텐츠 공급 위험 지도
→ 권역 선택
→ 공급·활동 리뷰어·신규 유입 원인 분석
→ CRM 후보 검토
→ 음식점·이벤트 콘텐츠 선택
→ 지역 활성화 캠페인 저장
→ 30·60·90일 관찰
```

지역 이벤트와 캠페인은 메시지 발송 기능이나 검증된 효과가 아니라 운영 가설이다.
실행 전 운영자 검토와 사후 비교 관찰이 필요하다.

## 3. 최종 정보 구조

사이드바는 조직 구조가 아니라 운영자가 수행할 업무 순서로 구성한다.

```text
개요
콘텐츠 공급 위험
파워 리뷰어 관리
신규 파워 유입
지역 활성화 캠페인
운영 결과·알림
운영 신뢰
설정
```

- 흰색 Yelp 사이드바를 유지한다.
- `권역 운영 홈`, `개인 운영 홈`은 최종 사이드바에서 제거한다.
- 기존 `/regional/home`, `/individual/home` 주소는 호환을 위해 유지하되 최종 업무
  화면으로 연결한다.
- `/`은 마케팅형 랜딩 화면이 아니라 지도와 우선 조치가 보이는 운영 개요다.

## 4. 용어와 대상의 역할

| 용어 | 역할 |
|---|---|
| 리뷰 공급 변화 | 권역별 콘텐츠 공급 상태를 판단하는 출발점 |
| 파워 리뷰어 | 선정 연도 코호트 정의를 충족한 핵심 콘텐츠 생산자 |
| 통합 검토 대상 | 통합 우선순위 상위 20% CRM 검토 대상; 확률이 아님 |
| 신규 파워 리뷰어 | 권역별 신규 유입 파생 결과 |
| 위험 유형 | 활동 변화의 주된 원인을 설명하는 운영 분류 |
| 관리자 판단 | 근거를 확인한 운영자의 조치 결정 |
| 실행안·캠페인 | 효과 검증 전 운영 가설 |

## 5. 데이터 원칙

- 기존 코호트, 시간 분할, 모델 결과와 DB/API 계약을 임의로 변경하지 않는다.
- 현재 화면의 운영 비교는 2017년 비교 → 2018년 선정·피처 마감 → 2019년 사후 검증
  구조를 따른다.
- 주간 집계가 없으므로 참고 이미지의 `최근 4주`와 주간 추이를 그대로 사용하지 않는다.
- 데이터로 계산되지 않은 효과 수치, 복귀율, 증가율을 만들지 않는다.
- 리뷰 활동 권역을 거주지·직장·실제 이동 경로로 표현하지 않는다.
- 클래스 점수와 통합 우선순위를 확률로 표현하지 않는다.
- 합성·데모 데이터가 필요하면 화면에 명시하며, 실제 데이터가 있으면 실제 데이터를
  우선한다.

## 6. 시각화 의미 체계

| 대상 | 표현 |
|---|---|
| 권역 공급 변화 | 행정구역 영역 색칠(choropleth) |
| 선택 권역 | 흰색 굵은 경계와 대표 활동 도시 핀 |
| 리뷰 활동 지점 | 작은 원형 점 |
| 음식점 후보 | 식기 아이콘 핀 |
| 추천 음식점 | 산호색 식기 아이콘 핀 |
| 위험·감소 | 산호색·빨강 |
| 선택·실행·회복 | 짙은 초록 |
| 데이터 없음 | 중립색 또는 사선 패턴 |

권역 위험을 원형 버블만으로 표현하지 않는다. 원형 점은 리뷰 활동 지점처럼 개별
관측 위치를 나타낼 때만 사용한다.

## 8. 재검토 조건

- 주·월 단위의 신규 시계열 집계가 추가되는 경우
- 실제 CRM 발송, 수신 동의, 이벤트 운영 시스템이 연동되는 경우
- 개인 실행안과 캠페인의 효과가 실험으로 검증되는 경우
- 권역 정의가 state에서 다른 단위로 변경되는 경우
- 파워 리뷰어 코호트 또는 통합 검토 정책이 변경되는 경우
