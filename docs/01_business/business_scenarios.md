# 핵심 리뷰어 리텐션 비즈니스 시나리오

> **문서 상태: 현재 기준**
> 최종 수정일: 2026-08-06
> 기준 모델: `v05_05_dl` Lifecycle Fusion H2

## 1. 비즈니스 정의

Yelp 음식 리뷰 공급 변화를 감지하고, 핵심 리뷰어 검토와 개인·지역 운영안
설계로 연결하는 리뷰 생태계 운영 서비스다.

`핵심 리뷰어`는 Yelp `Elite`와 같은 뜻이 아니다. 이 프로젝트에서는 선정 연도에
음식 관련 리뷰 10건 이상, 활동 월 3개월 이상을 충족한 분석 코호트를 뜻한다.

주요 사용자는 다음과 같다.

- 콘텐츠·커뮤니티 운영자
- 리뷰어 CRM 담당자
- 지역 콘텐츠 담당자
- 서비스 관리자

## 2. 해결하려는 문제

핵심 리뷰어의 음식 리뷰 활동이 약화되거나 중단되면 지역별 리뷰 공급과 음식점
정보의 최신성이 낮아질 수 있다. 운영자는 다음 질문에 답해야 한다.

1. 어느 권역과 도시의 리뷰 공급을 먼저 살펴야 하는가?
2. 어떤 핵심 리뷰어를 우선 검토해야 하는가?
3. 관찰된 활동 변화와 모델 점수는 무엇을 보여주는가?
4. 개인 특별 관리와 지역 캠페인 중 어떤 운영안을 검토할 것인가?
5. 판단·대상·실행안·재검토 이력을 어떻게 남길 것인가?

모델은 검토 순서를 돕는 참고 수단이며 운영자의 결정을 대신하지 않는다.

## 3. 데이터와 상태 정의

최종 Test는 비교 연도 2017년, 선정·피처 마감 연도 2018년, 실제 상태 검증 연도
2019년의 6,533명 코호트다.

| 상태 | 타깃 연도 조건 | 화면 의미 |
|---|---|---|
| `retained` | 리뷰 10건 이상이고 활동 월 3개월 이상 | 핵심 리뷰어 지위 유지 |
| `weakened` | 리뷰 1건 이상이며 리뷰 10건 미만 또는 활동 월 3개월 미만 | 리뷰 활동 약화 |
| `stopped` | 음식 관련 리뷰 0건 | 리뷰 활동 중단 |

`stopped`는 해당 타깃 연도의 음식 관련 리뷰가 0건이라는 뜻이다. Yelp 서비스 전체
이탈, 방문 활동 중단, 실제 생활 변화로 확대 해석하지 않는다.

## 4. 모델과 CRM 검토 정책

현재 최종 모델은 `v05_05_dl`이다.

| 지표 | 결과 |
|---|---:|
| OOF Macro F1 / Macro PR-AUC | 0.5763 / 0.5980 |
| OOF Precision@1000 | 90.60% |
| Final Test Macro F1 / Macro PR-AUC | 0.5731 / 0.5962 |
| Final Test Precision@1000 | 89.90% |
| Primary 검토 범위 | 위험 순위 상위 20%, 1,307명 |
| Top 20% Precision / Recall / Lift | 89.29% / 29.55% / 1.48배 |

`risk_score`와 클래스 점수는 보정된 이탈 확률이 아니라 상대적인 위험 순위를 정하는
모델 점수다. Primary 정책은 상위 20% 검토 대상과 일반 모니터링을 구분하고,
검토 대상 안에서는 약화 우세와 중단 우세를 별도 축으로 본다. 근거 없는
High·Medium·Low 절대 위험 등급은 사용하지 않는다.

## 5. 운영 흐름

```text
리뷰 공급 변화 감지
→ 감소·둔화 권역과 도시 선택
→ 핵심 리뷰어 활동 변화와 신규 유입 원인 확인
→ 우선 검토 큐에서 개별 근거 검토
→ 관리자 판단 기록
→ 개인 특별 관리 또는 지역 활성화 운영안 설계
→ 대상 명단·접촉·재검토 이력 확인
```

관리자 판단, 메모, 스누즈, 접촉, 대상 명단과 운영안은 서버 저장 기능이 연결돼 있다.
다만 최신 QA에서 보안·권역 격리·스누즈 복원·일부 회귀 결함이 확인돼 최종 배포
승인은 보류 상태다.

## 6. 개입 시나리오

| 상황 | 검토 목적 | 운영안 예시 |
|---|---|---|
| 활동 약화 신호가 뚜렷함 | 리뷰 활동 회복 가능성 검토 | 탐색 후보와 가벼운 재참여 메시지 검토 |
| 리뷰 활동이 장기간 없음 | 리뷰 재개 가능성 검토 | 복귀 안내와 핵심 혜택 검토 |
| 근거가 부족하거나 상충함 | 성급한 개입 방지 | 판단 보류와 재검토 일정 설정 |
| 권역 전반의 리뷰 공급이 감소함 | 개인 문제와 지역 문제 분리 | 지역 이벤트·콘텐츠 캠페인 검토 |

화면의 추천 음식점과 캠페인 후보는 운영 참고값이다. 방문·리뷰 작성·성과를
예측하거나 자동 CRM 발송을 의미하지 않는다.

## 7. 성과 평가와 한계

현재 확인된 것은 모델의 분류·순위 성능과 운영 기능의 구현·QA 결과다. 실제 캠페인
효과, 리뷰 재개율, 비용 대비 효과는 검증된 실행·성과 데이터가 없어 수치로 단정하지
않는다.

향후에는 다음 지표를 실제 데이터 계약과 함께 검증해야 한다.

- 접촉·참여·리뷰 재개율
- 30·60·90일 리뷰 공급 변화
- 개인·지역 운영안별 대조군 비교
- 개입 비용 대비 검증된 리뷰 공급 회복 효과
