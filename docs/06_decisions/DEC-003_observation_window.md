# DEC-003. 시간 구간 설정

> **문서 상태: 후속 결정으로 대체됨**
> 현재 코호트와 시간 구조는
> [DEC-010](DEC-010_v04_cohort_time_structure.md)을 따른다.

## 최종 결정

- 파워 리뷰어 선정 기간: 2017-01-01 이상, 2018-01-01 미만
- 활동 변화 관찰 기간: 2018-01-01 이상, 2019-01-01 미만
- 최근 활동 확인 기간: 2018-07-01 이상, 2019-01-01 미만
- 이탈 확인 기간: 2019-01-01 이상, 2020-01-01 미만

## 결정 근거

2019년은 음식점 리뷰가 608,268건 존재하는 완전한 1년이며,
코로나19 이전의 안정적인 활동 기간이다.

2020년에는 음식점 리뷰가 2019년 대비 약 41% 감소했으며,
개인의 탐방 루틴보다 코로나19라는 외부 환경이 이탈 타깃에 큰 영향을
줄 수 있어 메인 예측 기간에서 제외하였다.

기업이 매년 전년도 활동을 기준으로 파워 리뷰어를 선정한다고 가정하여
2017년을 연간 선정 기간으로 사용하였다.
