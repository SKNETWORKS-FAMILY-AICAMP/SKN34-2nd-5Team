| 항목 | 내용 |
|---|---|
| 상태 | 승인 |

## 1. 결정

기존 `churn` 이진 라벨을 삭제하지 않고, 파워 리뷰어의 다음 연도
활동 상태를 다음 세 클래스로 확장한다.

| 코드 | 영문명 | 화면 표현 | 타깃 연도 조건 |
|---:|---|---|---|
| 0 | `retained` | 파워 지위 유지 | 리뷰 10건 이상이고 활동 월 3개월 이상 |
| 1 | `weakened` | 파워 지위 약화 | 리뷰 1건 이상이며 리뷰 10건 미만이거나 활동 월 3개월 미만 |
| 2 | `stopped` | 리뷰 활동 중단 | 리뷰 0건 |

구현 우선순위는 활동 중단, 지위 약화, 지위 유지 순서다.

```python
if target_review_count == 0:
    retention_state = 2
elif target_review_count < 10 or target_active_months < 3:
    retention_state = 1
else:
    retention_state = 0
```

파워 지위 유지 조건의 여집합은 `리뷰 10건 미만 OR 활동 월 3개월
미만`이다. 두 조건을 모두 충족하지 못한 경우만 약화로 정의하는
`AND` 조건은 사용하지 않는다.

## 2. 기존 이탈 라벨과의 관계

`churn`은 DEC-004의 완전 활동 중단 정의로 계속 보존한다.

```text
churn = 1  ↔  retention_state = 2
```

`retention_state = 1`은 계정 탈퇴나 완전 이탈을 의미하지 않는다.
파워 리뷰어 연간 활동 기준을 충족하지 못한 상태를 의미한다.

## 3. 시간 분리와 누수 방지

- 선정 연도 활동으로 파워 리뷰어 코호트를 구성한다.
- 다음 연도의 활동 변화만 모델 입력 피처로 사용한다.
- 그다음 타깃 연도의 리뷰 수와 활동 월로 정답을 생성한다.
- `target_review_count`, `target_active_months`, `retention_state`,
  `churn`은 모델 입력에서 제외한다.
- 선정 연도 2017 표본은 최종 Test로 격리한다.

## 4. v03 기준 모델 정책

- 모델: 다중 `LogisticRegression`
- 피처: 기존 Core 43개
- 규제: L1
- `C`: 0.1
- 클래스 가중치: `balanced`
- 모델 선택: 확장형 시간 5-Fold
- 중단 점수 임계값: 0.45
- 약화 점수 임계값: 0.36
- 통합 우선순위: `weakened_score + stopped_score`

클래스별 모델 점수는 확률 보정 전 점수다. 실제 유지·약화·중단
확률로 표현하지 않는다.

## 5. 운영 해석

모델은 사용자의 상태를 자동 확정하거나 불이익을 결정하지 않는다.

제공한다.

- 약화 우세: 활동 회복 플레이북 검토
