# DEC-014. v05_05_dl 통합 미식 운영 컨텍스트

> **문서 상태: 현재 기준**
> 현재 운영 모델과 권역·도시·공급·반경·추천 컨텍스트에 적용한다.

## 문서 정보

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 승인일 | 2026-08-05 |
| 적용 버전 | `v05_05_dl` |
| 관련 결정 | DEC-007, DEC-010, DEC-012, DEC-013 |

## 1. 결정

`v05_05_dl` 예측 주변에 표시하는 권역·도시·공급·반경·추천 지표는 모두
Restaurants와 DEC-007에서 승인한 추가 미식 업종을 합친 동일한 음식점 범위를
사용한다. 기존 v04 산출물은 삭제하거나 덮어쓰지 않고 비교·롤백 기준으로 보존한다.

## 2. 변경하지 않는 것

- `v05_05_dl` 예측 점수, 예측 상태, CRM 상위 20% 정책은 재계산하지 않는다.
- 비교 연도 2017년, 선정 연도 2018년과 시간 누수 방지 원칙을 유지한다.
- 실제 거주지나 생활권으로 해석하지 않고 리뷰 활동 권역·도시로 표현한다.

## 3. 운영 컨텍스트 범위

다음 산출물은 `model_version='v05_05_dl'`로 함께 적재한다.

- 현재 리뷰어 권역과 대표 활동 도시
- 권역·도시별 리뷰 공급 및 신규 진입
- 도시 간 리뷰어 순유출입
- 리뷰어 활동 반경과 음식점 추천
- 매장별 리뷰 공급 변화
- 권역별 요일 패턴

현재 운영 대상 6,533명의 최초 코호트 진입 연도는
`reviewer_operating_entry`에 별도 저장한다. 전체 37,953행 과거 권역 이력은
감사·재현용 Parquet으로 보존하며, Test 코호트만 가진 `cohort_samples`에 과거
표본을 임의로 추가하지 않는다.

## 4. 요일 패턴 해석

- ISO 요일 1(월요일)~7(일요일)의 실제 리뷰 건수를 저장한다.
- 화면의 평일·주말 값은 각각 5일과 2일의 일평균을 계산한 뒤 두 강도의 합을
  100으로 정규화한 값이다. 단순 리뷰 건수 비중이 아니다.
- 선택 권역을 14개 권역 전체 기준선과 비교한다.
- 이 값은 캠페인 시작일 검토를 위한 운영 참고이며 캠페인 성과나 인과 효과를
  예측하지 않는다.

## 5. 영향과 롤백

통합 범위 적용 결과 2018년 Test 6,533명 중 기존 v04 대비 권역 29명,
대표 활동 도시 146명이 변경된다. 이에 따라 일부 지역 캠페인의 소속 대상자가
이동할 수 있다. 롤백 시 API의 파생 버전 상수를 `v04`로 되돌리며, 보존된 v04
DB 행과 Parquet을 사용한다.
