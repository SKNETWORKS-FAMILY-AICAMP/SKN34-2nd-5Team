## 1. 프로젝트 한 줄 정의

지역별 리뷰 공급 변화를 감지하고 원인을 분석한 뒤, 파워 리뷰어 특별 관리 또는
지역 활성화 캠페인으로 연결하는 리뷰 생태계 운영 서비스다.

```text
리뷰 공급 변화 감지
→ 활동 리뷰어·파워 리뷰어·신규 유입 원인 분석
→ 개인 특별 관리 또는 지역 활성화 캠페인
→ 30·60·90일 변화 관찰
```

## 2. 해결하려는 비즈니스 문제

파워 리뷰어가 떠나면 다음 문제가 발생할 수 있다.

- 리뷰 콘텐츠 감소
- 신규 음식점 정보 부족
- 검색 품질 저하
- 사용자의 방문 의사결정 약화
- 지역별 리뷰 공급 부족
- 광고 상품 가치 저하

현재 우선순위는 핵심 콘텐츠 생산자 유지와 CRM 대상 선정이다.

## 3. 모델링 문제

- 지도학습 3클래스 분류 v04
- 파워 지위 유지: 타깃 연도 리뷰 10건 이상, 활동 월 3개월 이상
- 파워 지위 약화: 리뷰 1건 이상이며 리뷰 10건 미만 또는 활동 월 3개월 미만
- 리뷰 활동 중단: 리뷰 0건
- 기존 `churn`은 리뷰 활동 중단과 동일한 이진 보조 검증 라벨로 보존
- 비교 연도 Y-1 → 선정·피처 마감 연도 Y → 타깃 연도 Y+1

## 4. 파워 리뷰어 기준

- 선정 연도 음식 관련 리뷰 10건 이상
- 선정 연도 활동 월 3개월 이상
- 기존 관찰 연도 하반기 연속성 조건은 v04에서 제거

기준값은 `configs/analysis_config.yaml`에서 관리한다.

## 5. 음식 관련 데이터 범위

Restaurants와 선별된 미식 방문형 카테고리를 사용한다.

- Restaurants: 52,268개 업체
- 미식 방문형 추가 업체: 5,888개
- 최종 업체: 58,156개
- 최종 리뷰: 4,950,264개

`Food` 전체는 Shopping, Drugstores, Grocery 등이 포함되므로 사용하지 않는다.

## 6. 롤링 코호트

- 학습: 선정 연도 2010~2016 후보를 사용한 확장형 시간 5-Fold
- 최종 학습: 선정 연도 2010~2017
- 최종 Test: 비교 2017 → 선정·피처 마감 2018 → 실제 상태 검증 2019
- 최종 Test 표본: 6,533명
- 2017년 비교 활동 없음: 1,692명
- 동일 사용자의 연도별 표본은 존재할 수 있음
- 시간 순서에 따른 분할을 유지해야 함

Useful·Cool·Funny 반응은 미래 정보 누수 가능성 때문에 현재 제외했다.

## 8. 최종 모델

v04 운영 기본 모델:

- 다중 LogisticRegression
- L1, C=0.01, class_weight=balanced
- Core 43개 피처
- 확장형 시간 5-Fold
- Test Macro F1: 0.5521
- Test Macro PR-AUC: 0.5792

Primary 운영 정책:

- `weakened_score + stopped_score` 통합 우선순위 상위 20%
- 대상 1,307명
- 실제 지위 상실 포착 1,142명
- 지위 상실 Precision 87.38%
- 지위 상실 Recall 28.92%
- Lift 1.45배
- 모델 판단: 유지 우세 2,332명, 약화 우세 3,038명, 중단 우세 1,163명

v04 사후 해석:

- 개별 피처와 그룹 중요도는 최종 Test 6,533명 기준 20회 Permutation
- 기준 지표는 Macro PR-AUC 0.579236
- 작성 간격 그룹이 가장 큰 PR-AUC 감소량을 보임
- 중요도는 모델 선정이 아닌 사후 해석 전용

클래스별 모델 점수는 보정된 상태 확률이 아니며 통합 큐는 관리자의
우선 검토 순위로 사용한다. 기존 v02 이진 모델은 비교 기준으로 보존한다.

## 11. 현재 런타임 구조

```text
React (app/)
  → FastAPI 읽기 전용 API (api/)
  → MySQL yelp_data
```

- 운영 홈, 리뷰어 관리, Reviewer 360, 플레이북, 지역 위험, Trust Center는 API를 조회한다.
- 위험 판단·근거·전략, 프로필 정규화, React 직렬화의 기준은 `shared/retention/`이다.
- `archive/app_streamlit_v04/core/`의 일부 모듈은 기존 import를 위한 호환 wrapper다.
- `app/src/data/*.json`은 정합성 확인·복구용이며 API 실패 시 자동 폴백하지 않는다.
- 관리자 판단은 현재 브라우저 `localStorage`에 저장하며 API와 DB는 읽기 전용이다.
