# Yelp 프로젝트 데이터 검증 미팅

## 1. 데이터 구현 가능성

- 음식점 업체: 52,268개
- 음식점 리뷰: 4,724,471건
- 음식점 리뷰 사용자: 1,445,990명
- Review → User 연결률: 99.9995%
- Review → Business 연결률: 100%

## 2. 최종 분석 대상

- 파워 리뷰어 기준: 연간 리뷰 10건 이상, 활동 3개월 이상
- 2017년 파워 리뷰어: 5,511명
- 최종 예측 대상: 3,908명
- 이탈자: 606명
- 이탈률: 15.51%

## 3. 강하게 확인된 이탈 신호

- 리뷰 작성량 감소
- 활동 월수 감소
- 리뷰 작성 간격 증가
- 마지막 리뷰 이후 공백 증가

## 4. 독립적인 신호로 확인되지 않은 가설

- 신규 음식점 탐색 비율 감소
- 카테고리 구성 다양성 감소
- 맛집 탐방 반경 축소

## 5. 보조 분석 후보

- 활동 중심지 이동
- 평균 평점 변화
- 저평점 비율 증가

## 6. 제외 피처

- Useful·Cool·Funny 반응: 반응 시점 부재로 데이터 누수 위험

## 7. 미팅 결정 필요 사항

- 현재 주제를 그대로 유지할 것인가?
- ‘탐방 루틴 붕괴’의 중심을 활동량과 작성 주기로 정의할 것인가?
- 공간 피처를 실험용으로 유지할 것인가?
- 파워 리뷰어 및 이탈 기준을 최종 확정할 것인가?
- 고도화 범위를 어디까지 포함할 것인가?
