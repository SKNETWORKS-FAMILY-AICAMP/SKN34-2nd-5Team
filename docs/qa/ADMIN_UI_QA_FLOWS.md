관련 문서: [QA 문서 안내](README.md) · [QA 계획](ADMIN_UI_QA_PLAN.md) · [QA 테스트 케이스](ADMIN_UI_QA_CASES.md) · [최신 실행 결과](ADMIN_UI_QA_EXECUTION_2026-08-05.md)

## 1. 전체 관리자 E2E 흐름

```mermaid
flowchart TD
    A["관리자 로그인"] --> B{"세션·권한 확인"}
    B -->|실패| C["로그인 화면 이동 및 오류 확인"]
    B -->|ADMIN| D["콘텐츠 공급 위험"]
    D --> E{"운영 경로 선택"}
    E -->|개인| F["핵심 리뷰어 큐 필터·선택"]
    F --> G["Reviewer 360 근거 검토"]
    G --> H["관리자 판단·메모·스누즈 저장"]
    H --> I["접촉 이력 기록"]
    I --> J["개인 특별 관리안 설계·저장"]
    E -->|권역| K["권역·도시·위험 관점 선택"]
    K --> L["CRM 대상·음식점 후보 선택"]
    L --> M["권역 캠페인 검토 명단·운영안 저장"]
    J --> N["운영 결과·알림에서 영속성 확인"]
    M --> N
    N --> O["재검토 알림 완료 또는 제외"]
    O --> P["설정에서 사용자·권한 관리"]
    P --> Q["로그아웃 및 세션 폐기 확인"]
```

판정 포인트는 각 저장 직후 성공 메시지만이 아니라 새로고침 후 동일 데이터가 다시
조회되는지, 운영 결과·알림에 같은 대상과 담당자가 연결되는지다.

## 2. 인증·세션·권한 흐름

```mermaid
flowchart TD
    A["React 직접 접속"] --> B["GET /auth/api/me"]
    B --> C{"응답"}
    C -->|200 ADMIN| D["관리자 화면 렌더링"]
    C -->|401·403| E["/auth/login 이동"]
    C -->|5xx·네트워크 실패| F["보호 화면 유지·오류 조사"]
    D --> G["변경 요청"]
    G --> H{"세션 쿠키·CSRF·역할"}
    H -->|정상| I["서버 저장 및 감사 이력"]
    H -->|세션 없음| J["401, 저장 없음"]
    H -->|VIEWER| K["403, 저장 없음"]
    H -->|CSRF 오류: 인증 관리 API| L["403, 계정 변경 없음"]
    D --> M["로그아웃"]
    M --> N["세션 폐기·쿠키 제거·로그인 이동"]
```

## 5. 관리자 계정 수명주기

```mermaid
stateDiagram-v2
    [*] --> PENDING: 회원가입 신청
    PENDING --> APPROVED: 관리자가 VIEWER 또는 OPERATOR로 승인
    PENDING --> REJECTED: 관리자가 거절
    APPROVED --> SUSPENDED: 비활성화
    SUSPENDED --> APPROVED: 활성화
    APPROVED --> APPROVED: 역할·담당 권역 변경
    APPROVED --> APPROVED: 비밀번호 재설정·기존 세션 종료
    REJECTED --> [*]
```

관리자(`ADMIN`) 계정 자체는 화면에서 생성·역할 변경·비밀번호 재설정하지 않고 서버
CLI 정책을 유지한다.
