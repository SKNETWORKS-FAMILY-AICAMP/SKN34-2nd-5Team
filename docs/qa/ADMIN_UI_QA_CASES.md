# 관리자 UI QA 테스트 케이스

관련 문서: [QA 문서 안내](README.md) · [QA 계획](ADMIN_UI_QA_PLAN.md) · [QA 흐름도](ADMIN_UI_QA_FLOWS.md) · [최신 실행 결과](ADMIN_UI_QA_EXECUTION_2026-08-05.md)

## 실행 표기

- 우선순위: `P0` 스모크/차단, `P1` 핵심 기능, `P2` 보조·표현·접근성
- 결과: 실행자가 `PASS`, `FAIL`, `PARTIAL`, `NOT RUN` 중 하나를 기록한다.
- `PARTIAL`은 기대 결과의 일부만 확인한 경우, `NOT RUN`은 환경·데이터·안전상의 이유로 실행하지 않은 경우다.
- 실제 리뷰어·권역·수치는 화면/API에 존재하는 값을 사용하며 임의 수치를 만들지 않는다.
- 쓰기 케이스는 변경 전 값을 기록하고 종료 후 복구한다.
